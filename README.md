## 📌 Visão Geral

O **Gerador de Certificados PVA (Programa de Voluntariado Acadêmico)** é uma ferramenta desenvolvida para eliminar o retrabalho manual na emissão de certificados acadêmicos na Universidade Federal do Paraná (UFPR).

A aplicação foi reformulada para rodar **inteiramente no navegador**, sem a necessidade de instalar interpretadores Python, pacotes adicionais ou ferramentas de terminal. O processamento da planilha de participantes e a renderização gráfica dos certificados são executados localmente, garantindo total privacidade e velocidade instantânea.

> [!NOTE]
> Para acessar a versão clássica desenvolvida originalmente em Python puro (Pillow/Pandas), consulte a branch [`python-version`](https://github.com/brunomarafiga/Criacao_certificados/tree/python-version).

## 🚀 Como Usar

### 🔗 Acesso Imediato
Acesse a aplicação pronta no GitHub Pages:  
👉 **[brunomarafiga.github.io/Criacao_certificados](https://brunomarafiga.github.io/Criacao_certificados/)**

### 📋 Passo a Passo
1. **Prepare sua Planilha Excel (`.xlsx`):**  
   Estruture a lista com as colunas de nome, carga horária, função e dados da atividade.
2. **Importação Direta:**  
   Arraste o arquivo `.xlsx` para dentro da área pontilhada na interface.
3. **Pré-visualização e Validação:**  
   Verifique como o layout do certificado oficial da UFPR se ajusta aos nomes longos.
4. **Download em Lote:**  
   Gere e baixe todos os certificados em formato de alta resolução prontos para impressão ou envio digital.

## 🛡️ Vantagens e Segurança

- **Zero Instalação:** Funciona em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).
- **Sigilo de Dados:** Nenhuma informação dos participantes é enviada a servidores externos, em estrito acordo com a LGPD.
- **Renderização em Canvas:** Tipografia nítida e alinhamento visual preciso baseado no modelo gráfico institucional da UFPR.
